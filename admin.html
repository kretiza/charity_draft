A few useful things to know

  • Use START-WEBSITE.cmd for consistent storage across all seven pages.
  • Use the same browser and the same local website address each time.
  • Clearing browser data also clears this demo’s stories and uploads.
  • The files in your website folder are not changed by the admin.
  • “Published” means visible in your local demo; it does not upload anything to the internet.
  • Uploaded videos stay in your browser. YouTube playback requires an internet connection and may depend on the video’s embedding settings.
  • A future online version will need shared storage and a protected admin account.
